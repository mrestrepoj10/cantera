# Templates

Ready-to-deploy Next.js apps, one per cantera template. Each directory is generated from the
registry by `pnpm registry:build` and is what the Deploy button on the site clones.

| Template | What it is | Links |
| --- | --- | --- |
| [ACC Sign-In](./acc-sign-in) | A ready-made /sign-in page on acc-auth-routes: the scoped sign-in when signed out, and a live connection panel — account, token expiry, held scopes — once connected. | [Deploy](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fmrestrepoj10%2Fcantera%2Ftree%2Fmain%2Ftemplates%2Facc-sign-in&project-name=cantera-acc-sign-in&repository-name=cantera-acc-sign-in&env=APS_CLIENT_ID%2CAPS_CLIENT_SECRET%2CSESSION_SECRET&envDescription=APS+app+credentials+and+a+session+secret.+The+README+explains+each+key.&envLink=https%3A%2F%2Fcanteraui.vercel.app%2Fcomponents%2Facc-sign-in) · [Docs](https://canteraui.vercel.app/components/acc-sign-in) |
