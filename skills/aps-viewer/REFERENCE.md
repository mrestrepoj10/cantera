# APS Viewer Reference Index

This file is intentionally short. Load only the specific reference needed for the task:

- [references/viewer3d.md](references/viewer3d.md): Viewer runtime, Viewer3D method families, model loading, selection, properties, state, screenshots, events, multi-model, and teardown.
- [references/extensions.md](references/extensions.md): Extension lifecycle, registration/loading options, async dependencies, toolbar and docking panels, state persistence, and `aps-extensions` repo patterns.
- [references/custom-ui.md](references/custom-ui.md): Viewer-owned UI guidance for toolbar buttons, control groups, docking panels, property panels, embedded grids/charts/React roots, and cleanup.
- [references/tutorial-patterns.md](references/tutorial-patterns.md): Practical patterns from Simple Viewer, Hubs Browser, and Dashboard tutorials.
